## Getting started

Open a Claude Code session in this directory and read
**[START-HERE.md](./START-HERE.md)**. It is the idea-to-ship playbook: which
skill to reach for, in what order, and where the boundaries are.

If you would rather be routed than read, type `/ask-matt`.

## What is already wired up

The [`mattpocock-skills`](https://github.com/mattpocock/skills) plugin, enabled
for this project in `.claude/settings.json`, plus the per-repo config those
skills expect:

| Path | What it is |
|---|---|
| `START-HERE.md` | The idea-to-ship playbook |
| `CLAUDE.md` | Project instructions, with the `## Agent skills` block. `AGENTS.md` symlinks to it |
| `CONTEXT.md` | The glossary. Filled in lazily by `/grill-with-docs`, not upfront |
| `docs/adr/` | Architecture decision records |
| `docs/agents/issue-tracker.md` | Where issues live. Set to local markdown |
| `docs/agents/domain.md` | How skills should read `CONTEXT.md` and ADRs |
| `docs/agents/triage-labels.md` | The five triage roles mapped to label strings |
| `.scratch/` | The issue tracker itself. Committed, not ignored |

If the plugin is not installed on the machine you clone this to:

```bash
claude plugins install mattpocock-skills
```

It is in Claude Code's official marketplace, so there is nothing to add first,
and updates arrive automatically.
